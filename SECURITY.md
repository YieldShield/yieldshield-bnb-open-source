# Security policy

YieldShield BNB is a BSC Testnet demo using valueless synthetic tokens. The current `main` branch, deployed chain-97 contracts, web app, market-data API, and deployment tooling are the supported scope. BSC mainnet prices shown under `/learn/scenarios` are read-only references; there is no mainnet protection deployment.

Report a suspected vulnerability privately to david@yieldshield.ai with “YieldShield BNB security” in the subject, or use GitHub private vulnerability reporting when it is enabled for this repository. Do not post exploit details in a public issue. Include the affected component and network, reproduction steps, expected impact, and relevant transaction hashes or addresses. Never send a private key or seed phrase.

The [dated internal engineering review](docs/BNB_SECURITY_REVIEW_2026-09-23.md) records scoped tests and known limitations. It is not an independent audit or a statement that the contracts are safe for real assets. Do not send real BNB or valuable tokens to the testnet contracts.
