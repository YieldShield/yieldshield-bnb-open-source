# BNB edition baseline

The BNB edition starts from the committed YieldShield Base application at
`e2bc6adb77d23ffb8b6d35738dfce0a7d94afcea` (8 September 2026), from
https://github.com/YieldShield/yieldshield-base.

This initial snapshot preserves the source implementation and its license notices.
BNB-specific changes follow in separate commits. Uncommitted work in the Base
checkout is not included. Historical Base contract reviews and deployments are
inherited reference material and do not attest a BNB deployment or audit.

The BNB release will use yellow branding, cryptocurrency token references on BSC
mainnet, and an illustrative protection scenario. Wallet contract interactions
must remain unavailable until a separately verified BSC testnet deployment exists.
